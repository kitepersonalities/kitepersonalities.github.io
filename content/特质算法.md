# 特质评分算法

> 本文档定义「潍坊风筝人格测试」的评分规则。题目见 `故事题.md`，特质文案见 `工具特质.md` / `风筝特质.md`。
> 核心目标：消除题库中各特质出现次数不均带来的偏差，用「得分率」而非「原始分」公平比较。

---

## 一、计分规则（原始分）

- 每题**单选**，选了哪个选项，就把该选项背后的**每一个**特质各 +1。
- 多标签选项（如「联结 / 统领」）被选中时，两个特质**都** +1，不做均分。

例：选「第 9 题 D（有趣的灵魂 / 热情）」→ 有趣的灵魂 +1，热情 +1。

---

## 二、归一化（得分率）

每个特质的**得分率** = 原始分 ÷ 该特质在 14 题中的**出现总次数**。

- 出现次数是**固定常量**（见文末附录），与用户无关。
- 得分率落在 0~1 之间，不同特质的得分率可直接比较。

> 为什么必须归一化：题库里「理性」出现 15 次、「博弈」只出现 4 次。若直接比原始分，出现多的特质天然占优。除以出现次数后，两者才公平。

---

## 三、主导判定（两个维度独立）

- **工具维度**：6 个工具各自算得分率，最高者 = **主导工具**。
- **风筝维度**：6 个风筝各自算得分率，最高者 = **主导风筝**。
- 两者**独立**比较，互不干扰（类似 MBTI 的 E/I 与 S/N 各自独立成对）。

---

## 四、均衡型处理（并列双主导）

设某维度内 top1、top2 的得分率差为 `gap = top1 - top2`：

- `gap > 0.1` → **典型型**：只取 top1 为主导。
- `gap ≤ 0.1` → **并列双主导**：展示「top1 与 top2 的混合体」，两者并列。

> 阈值 `0.1` 是默认建议值：多数维度出现 7~10 次，一道题贡献 ≈ 1/7 ~ 1/10（约 0.1~0.14），`gap < 0.1` 基本意味着「差距不到一道题」，判并列合理。此阈值可调。

---

## 五、结果输出

最终人格 = **主导工具 × 主导风筝**（各自可能含并列逻辑）。

- **主结论**：主导工具 × 主导风筝，如「果断 × 自由」。
- **副特质彩蛋**：工具维度的 top2 与风筝维度的 top2，作为「隐藏副特质」附一句展示；若已并列，则彩蛋与主结论合并为「混合体」叙述。

## 示例演算

假设某用户逐题选择：1C、2A、3D、4B、5C、6A、7C、8A、9D、10A、11C、12B、13E、14A。

**工具维度原始分 / 得分率：**

| 工具 | 原始分 | 得分率 |
|------|:---:|:---:|
| 果断 | 0 | 0/7 = 0 |
| 耐心 | 2 | 2/10 = 0.20 |
| 热情 | 2 | 2/4 = **0.50** |
| 创造 | 3 | 3/10 = 0.30 |
| 灵活应变 | 2 | 2/4 = **0.50** |
| 联结 | 2 | 2/7 ≈ 0.29 |

→ 热情 0.50 与 灵活应变 0.50 并列（gap = 0），工具 = **「热情 × 灵活应变」并列双主导**。
（注意：创造原始分 3 分最高，但归一化后反而不如热情——这正是归一化的作用。）

**风筝维度原始分 / 得分率：**

| 风筝 | 原始分 | 得分率 |
|------|:---:|:---:|
| 统领 | 3 | 3/5 = **0.60** |
| 守正 | 0 | 0 |
| 博弈 | 1 | 1/4 = 0.25 |
| 自由 | 0 | 0 |
| 有趣的灵魂 | 4 | 4/10 = 0.40 |
| 理性 | 2 | 2/15 ≈ 0.13 |

→ 统领 0.60 最高，次高 有趣的灵魂 0.40，gap = 0.20 > 0.1，风筝 = **统领（典型型）**，副彩蛋 = 有趣的灵魂。

**最终结果**：主导工具「热情 × 灵活应变」（并列）× 主导风筝「统领」，副特质彩蛋「有趣的灵魂」。
